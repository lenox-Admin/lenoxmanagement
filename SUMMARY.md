### Step 1: Update Business Information (15 minutes)
Edit these files and replace placeholder information:
- index.html
- contact.html
- services.html

Update:
- Address
- Phone number
- Email
- Business hours
- Geographic coordinates
- Social media URLs

### Step 2: Upload Files (10 minutes)
Upload to your website root:
- robots.txt
- sitemap.xml
- .htaccess
- index.html
- contact.html (to /contact/ directory)
- services.html (to /services/ directory)

### Step 3: Verify HTTPS (5 minutes)
- Ensure SSL certificate is installed
- Test: https://www.lenoxmanagement.com
- Verify .htaccess redirects work

### Step 4: Set Up Search Console (15 minutes)
- Create Search Console account
- Verify ownership
- Submit sitemap

### Step 5: Set Up Analytics (10 minutes)
- Create Google Analytics account
- Update tracking code in HTML files
- Verify tracking works

**Total time: ~55 minutes**
