# Meta Tags Template Reference

Quick copy-paste templates for different page types. Replace [PLACEHOLDERS] with actual content.

## Homepage

```html
<title>[Business Name] - [Primary Service/Value Proposition]</title>
<meta name="description" content="[Business Name] provides [main services]. [Key benefits or USP]. [Location if local business]. [Call to action].">

<!-- Example -->
<title>Lenox Management - Professional Property Management Services</title>
<meta name="description" content="Lenox Management provides comprehensive property management services including residential and commercial property oversight, tenant management, and 24/7 support. Contact us today!">
```

## Services/Products Page

```html
<title>[Service Name] | [Service Type] | [Business Name]</title>
<meta name="description" content="[Service description]. [Key features/benefits]. [Target audience]. [Call to action].">

<!-- Example -->
<title>Property Management Services | Residential & Commercial | Lenox Management</title>
<meta name="description" content="Full-service property management for residential and commercial properties. Tenant screening, rent collection, maintenance coordination. Call us today!">
```

## About Page

```html
<title>About [Business Name] - [Company Story/Mission]</title>
<meta name="description" content="Learn about [Business Name]'s [history/experience/mission]. [Key differentiators]. [Team/expertise]. [Call to action].">

<!-- Example -->
<title>About Lenox Management - Expert Property Management Team</title>
<meta name="description" content="Learn about Lenox Management's 15+ years of property management experience. Meet our expert team dedicated to providing exceptional service. Contact us today!">
```

## Contact Page

```html
<title>Contact [Business Name] - [Call to Action]</title>
<meta name="description" content="Contact [Business Name] [for what]. [Contact methods]. [Hours/availability]. [Response time/promise].">

<!-- Example -->
<title>Contact Lenox Management - Get in Touch Today</title>
<meta name="description" content="Contact Lenox Management for property management services. Call, email, or visit our office. Open Monday-Friday 9 AM-5 PM. Fast response guaranteed.">
```

## Blog Post

```html
<title>[Post Title] | [Business Name] Blog</title>
<meta name="description" content="[Brief summary of the post content]. [Key takeaway or benefit]. [Call to action].">

<!-- Example -->
<title>5 Tips for First-Time Landlords | Lenox Management Blog</title>
<meta name="description" content="Essential tips for first-time landlords: tenant screening, lease agreements, maintenance, and more. Learn how to succeed as a property owner. Read more!">
```

## Property/Product Listing

```html
<title>[Property/Product Name] - [Key Features] | [Business Name]</title>
<meta name="description" content="[Property/Product description]. [Key features]. [Price/availability]. [Location]. [Call to action].">

<!-- Example -->
<title>3-Bedroom Apartment - Modern Downtown Living | Lenox Management</title>
<meta name="description" content="Beautiful 3-bed, 2-bath apartment in downtown. Updated kitchen, washer/dryer included. $2,000/month. Schedule a viewing today!">
```

## Location/Service Area Page

```html
<title>[Service] in [City/Area] | [Business Name]</title>
<meta name="description" content="[Service] in [Location]. [Local benefits/expertise]. [Service details]. [Call to action].">

<!-- Example -->
<title>Property Management in Austin, TX | Lenox Management</title>
<meta name="description" content="Professional property management in Austin, Texas. Local expertise, responsive service, proven results. Serving residential and commercial properties. Contact us!">
```

## FAQ Page

```html
<title>Frequently Asked Questions | [Business Name]</title>
<meta name="description" content="Common questions about [main topics]. [Key questions]. Get answers about [topics]. [Call to action].">

<!-- Example -->
<title>Property Management FAQs | Lenox Management</title>
<meta name="description" content="Get answers to common property management questions: fees, services, tenant screening, maintenance, and more. Find the information you need here.">
```

## Character Limits

### Title Tags
- **Optimal:** 50-60 characters
- **Maximum:** 70 characters (beyond this gets truncated)
- **Mobile:** 55-60 characters (may be shorter on mobile)

### Meta Descriptions
- **Optimal:** 150-160 characters
- **Maximum:** 160 characters
- **Mobile:** 120 characters (may be shorter on mobile)

---

## Best Practices Checklist

### Title Tags
- [ ] 50-60 characters
- [ ] Includes primary keyword near the beginning
- [ ] Includes brand name (usually at the end)
- [ ] Unique for every page
- [ ] Compelling and accurate
- [ ] No keyword stuffing
- [ ] No all caps or excessive punctuation

### Meta Descriptions
- [ ] 150-160 characters
- [ ] Includes primary keyword naturally
- [ ] Contains call-to-action
- [ ] Unique for every page
- [ ] Compelling and accurate
- [ ] Provides value to readers
- [ ] No duplicate descriptions

---

## Common Mistakes to Avoid

❌ **Don't:**
- Use the same title/description on multiple pages
- Keyword stuff
- Use all caps
- Exceed character limits
- Be vague or generic
- Leave them blank
- Use special characters excessively

✅ **Do:**
- Make each page unique
- Front-load important keywords
- Write for humans, not just search engines
- Include location (if local business)
- Add compelling calls-to-action
- Match the actual page content
- Test in Google SERP preview tool

## Keywords Placement Priority

### Title Tag (Most Important)
1. Primary keyword (near the beginning)
2. Secondary keyword or modifier
3. Brand name

**Example:** "Property Management Services | Residential & Commercial | Lenox Management"
- Primary: "Property Management Services"
- Secondary: "Residential & Commercial"
- Brand: "Lenox Management"

### Meta Description
1. Primary keyword (in first sentence)
2. Related keywords naturally
3. Call-to-action

**Example:** "Lenox Management provides property management services for residential and commercial properties. Tenant screening, maintenance, 24/7 support. Contact us today!"

## Title Tag Formulas

### Service Page
```
[Service] | [Benefit/Type] | [Brand]
[Service] - [Location] | [Brand]
[Adjective] [Service] | [Brand]
```

### Product Page
```
[Product Name] - [Key Feature] | [Brand]
[Product] | [Benefit] - [Brand]
```

### Blog Post
```
[Number] [Topic] for [Audience] | [Brand]
How to [Action] | [Brand] Blog
[Topic]: [Subtitle] | [Brand]
```

### Location Page
```
[Service] in [City, State] | [Brand]
[City] [Service] | [Brand]
```


### Product
```

```

## Open Graph Tags Template

```html
<meta property="og:type" content="website">
<meta property="og:url" content="[PAGE_URL]">
<meta property="og:title" content="[TITLE - can be different from title tag]">
<meta property="og:description" content="[DESCRIPTION - can be different from meta description]">
<meta property="og:image" content="[IMAGE_URL - 1200x630px]">
<meta property="og:site_name" content="[BUSINESS_NAME]">
<meta property="og:locale" content="en_US">
```

## Testing Your Meta Tags

### Preview Tools
- Google SERP Preview: https://metatags.io/
- Facebook Debugger: https://developers.facebook.com/tools/debug/
- Twitter Card Validator: https://cards-dev.twitter.com/validator
- LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/

### Check Your Pages
After implementation, test each page:
1. Google search for `site:yoursite.com`
2. Check how title and description appear
3. Use testing tools above
4. Search on mobile to see mobile display
5. Share on social media to test OG tags
